# Lib Downloader — MangaLib / SlashLib / HentaiLib

Готовое расширение Chrome (Manifest V3) для скачивания **общедоступных** глав с `mangalib.me`, `v2.shlib.life` (SlashLib / YaoiLib) и `hentailib.me` (HentaiLib). Все три сайта работают через один API сети lib.social и различаются только заголовком `Site-Id`. Работает без сборки, npm-зависимостей, внешних CDN и серверов-прокси.

## Возможности

- Три независимых профиля: **MangaLib** (`Site-Id: 1`), **SlashLib** (`Site-Id: 2`), **HentaiLib** (`Site-Id: 4`). У каждого свои origin, список API и CDN.
- Автоматически определяет сайт по ссылке из активной вкладки; для голого `slug` есть выпадающий список «Сайт: авто / MangaLib / SlashLib / HentaiLib».
- Подставляет ссылку на тайтл из страницы MangaLib / SlashLib / HentaiLib или из читалки. Голый `slug` и ссылка без `https://` тоже принимаются.
- Показывает список глав с подписями колонок («Том, глава», «Название», «Перевод», «Статус»): том, номер, название, число переводов, закрытые главы.
- Выбор глав чекбоксами или кликом по всей строке, `Shift + клик` (и `Shift + ↑/↓`) для диапазона, фильтр и диапазон вида `1-10, 15, 20.5`.
- Выбор ветки перевода, если у главы их несколько; явно передаётся `branch_id`.
- Форматы:
  - **Один CBZ — папки по главам** (по умолчанию): внутри отдельная папка на каждую главу, например `001 - т01 гл0001 - Название/`, со страницами `001.jpg`, `002.jpg` и своим `ComicInfo.xml`; в корне общие `chapters.txt` и `ComicInfo.xml`. 50 глав дают 50 понятных папок, а не 900 безымянных файлов; браузер получает **один файл в конце**;
  - **Один CBZ — сплошные страницы**: прежний плоский вариант `0001.jpg`, `0002.jpg`, … для ридеров, которые не умеют вложенные папки; границы глав записаны в `chapters.txt` и `ComicInfo.xml`;
  - **Один ZIP — CBZ по главам**: один общий `.zip`, внутри отдельные `.cbz` на каждую главу и `chapters.txt`; тоже один файл в конце;
  - **CBZ — архив на главу**: старый режим, по одному `.cbz` на главу;
  - **Отдельные изображения** — папка на главу;
  - **CBZ + изображения**.
- Три режима скорости, параллельная загрузка страниц, паузы, ретраи при `429`/`5xx`, обработка `Retry-After`.
- Несколько адресов API и несколько CDN-серверов с автоматическим перебором.
- При `404` перебирает `Site-Id` других сайтов сети (1 / 2 / 4) и переключает профиль целиком — включая API, CDN и `Referer`.
- Читает `access_token` из `localStorage` открытой вкладки и добавляет `Authorization: Bearer …` — это нужно для части 18+ тайтлов SlashLib и HentaiLib. Токен уходит **только** на хосты API своего профиля (`api.cdnlibs.org`, `api.lib.social`, `api.shlib.life`), но не на запасные CDN и не на чужие API.
- Запоминает формат, скорость и папку в загрузках между запусками (`chrome.storage.local`).
- Если главы всё равно недоступны, показывает понятное сообщение и предлагает похожие тайтлы из каталога lib.social.
- При нажатии **Остановить** в режимах «Один …» не теряет скачанное: отдаёт частичный архив из завершённых глав и уже загруженных страниц текущей главы, помечая их как неполные.
- Определяет реальный формат картинки по magic-байтам: CDN может отдавать JPEG под именем `.png`.
- Прогресс по главам и страницам, журнал ошибок, кнопка «Остановить».

## Установка

1. Скачайте репозиторий (Code → Download ZIP на GitHub) и распакуйте его в **постоянную** папку. Не удаляйте и не перемещайте её после установки: Chrome грузит код из этой папки.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой лежит `manifest.json` (корень репозитория).
5. Закрепите иконку расширения на панели браузера — это удобно, но не обязательно.

Сборка не нужна: `manifest.json`, `app.html`, `app.css`, `app.js`, `core.js`, `background.js`, `fonts/` и `icons/` — это и есть готовое расширение. Отдельного ZIP-архива в репозитории нет.

Подходит для Chrome и других актуальных Chromium-браузеров с Manifest V3 (Edge, Brave, Opera, Яндекс Браузер). После обновления файлов нажмите «Обновить» на карточке расширения.

## Использование

1. Откройте страницу тайтла или главу на `https://mangalib.me/...`, `https://v2.shlib.life/...` либо `https://hentailib.me/...`.
2. Нажмите иконку расширения. Откроется отдельная вкладка загрузчика — ссылка и сайт подставятся автоматически.
3. Если вставляете ссылку вручную, можно просто нажать **Загрузить список**. Если вставляете только `slug` вроде `87161--san-da`, выберите нужный сайт в выпадающем списке — иначе будет использован сайт из предыдущей загрузки.
4. Отметьте главы. Если глава открыта в читалке, она будет выделена автоматически.
5. Для глав с несколькими переводами выберите команду в выпадающем списке.
6. Выберите формат, скорость и папку в загрузках. По умолчанию стоит **Один CBZ — папки по главам**.
7. Нажмите **Скачать выбранные**. В режимах «Один …» файл не появится сразу: расширение соберёт все страницы в памяти и отдаст **один архив в конце**. Если нажать **Остановить** на полпути, оно всё равно соберёт и отдаст **частичный архив** из уже скачанного.

В режиме по умолчанию результат выглядит так:

```text
SlashLib/
  Санда - т01 гл0001–т01 гл0005 (5 глав).cbz
    chapters.txt       # список папок, глав, названий и переводов
    ComicInfo.xml      # общие метаданные
    001 - т01 гл0001 - Название главы/
      001.jpg
      002.jpg
      ...
      ComicInfo.xml    # метаданные конкретной главы
    002 - т01 гл0002 - Название главы/
      001.jpg
      ...
      ComicInfo.xml
    ...
```

В режиме **Один ZIP — CBZ по главам**:

```text
SlashLib/
  Санда - т01 гл0001–т01 гл0005 (5 глав).zip
    Санда - т01 гл0001.cbz
    Санда - т01 гл0002.cbz
    ...
    chapters.txt
```

Старые режимы по-прежнему сохраняют по файлу/папке на главу. Chrome может спросить разрешение на сохранение нескольких файлов; в режимах «Один …» такой запрос будет только для одного архива. Если появится запрос доступа к новому серверу изображений, его тоже нужно подтвердить.

## Как устроено

Живые проверки выполнены 2026-11-03 для MangaLib и SlashLib; профиль HentaiLib добавлен 2026-11-07 по тому же API (`Site-Id: 4`, тот же `api.cdnlibs.org`).

| Параметр | MangaLib | SlashLib / `v2.shlib.life` | HentaiLib / `hentailib.me` |
|---|---|---|---|
| `Site-Id` | `1` | `2` (совпадает с `<html data-id="2">`) | `4` (совпадает с `<html data-id="4">`) |
| Основной API | `https://api.cdnlibs.org/api` | `https://api.shlib.life/api` | `https://api.cdnlibs.org/api` |
| Запасные API | `api.lib.social`, `api2.mangalib.me` | `hapi.hentaicdn.org`, `api.cdnlibs.org`, `api.lib.social` | `api.lib.social`, `api2.mangalib.me` |
| Заголовки | `Site-Id`, `Accept: application/json`, непустой `Referer` | те же | те же |
| Список глав | `GET /manga/{slug}/chapters` | тот же | тот же |
| Метаданные | `GET /manga/{slug}` | тот же | тот же |
| Страницы | `GET /manga/{slug}/chapter?number=…&volume=…[&branch_id=…]` | тот же | тот же |
| CDN | `img3.cdnlibs.org`, `img3.cdnrulib.link` | `img3.hentaicdn.org`, затем общие запасные серверы | `img3.hentaicdn.org`, `img3.cdnlibs.org`, `img3.cdnrulib.link` |
| Домены | `mangalib.me`, `mangalib.org` | `shlib.life`, `yaoilib.net`, `slashlib.me`, `slashlib.org` | `hentailib.me`, `hentailib.org` |

`Site-Id` дополнительно читается из атрибута `<html data-id="…">` открытой вкладки; если вкладка недоступна, используется значение профиля. `Referer` подставляется отдельным правилом `declarativeNetRequest`: WAF/DDoS-Guard может отвергать запросы без него, а обычный `fetch()` не разрешает выставлять этот заголовок. Правило ограничено инициаторами «само расширение + поддерживаемые сайты» и только известными доменами API/CDN.

Если прямой запрос со страницы расширения отвергнут, расширение повторяет его в контексте открытой вкладки **того же сайта**: так сохраняются origin, `Referer` и cookies браузера. Поэтому для надёжности желательно не закрывать исходную вкладку MangaLib/SlashLib/HentaiLib.

Для тайтлов с возрастным ограничением сайт может требовать авторизацию: расширение один раз считывает `access_token` из `localStorage` открытой вкладки и отправляет его как `Authorization: Bearer …` только на хосты API своего профиля (`api.cdnlibs.org`, `api.lib.social`, `api.shlib.life`). Список разрешённых хостов — поле `authHosts` в `SITE_PROFILES` (`core.js`); запасные CDN (`img3.*`, `hapi.hentaicdn.org`) и чужие API токен не получают. Токен не сохраняется в файлах и не логируется. Если API всё равно отвечает `404`, расширение перебирает другие `Site-Id` (1 / 2 / 4), переключает профиль целиком и в конце предлагает похожие тайтлы из каталога.

CBZ/ZIP создаётся локально как ZIP методом `STORED`: JPEG/PNG/WebP уже сжаты, повторное deflate-сжатие только нагружает процессор. Имена файлов в архиве — UTF-8. `ComicInfo.xml` содержит название, том, номер главы, команду перевода и число страниц. В режиме по умолчанию общий CBZ содержит **папку на каждую главу**: внутри страницы и `ComicInfo.xml` этой главы, а в корне — общие `chapters.txt` и `ComicInfo.xml`. Плоский вариант «Один CBZ — сплошные страницы» оставлен для читалок, которые не поддерживают вложенные папки: там страницы идут одной последовательностью, а границы глав записаны в `chapters.txt` и `Summary` внутри `ComicInfo.xml`. В общем ZIP каждая глава остаётся отдельным CBZ со своим `ComicInfo.xml`. Все «Один …» режимы вызывают `chrome.downloads.download` ровно один раз — после завершения всей пакетной загрузки **или сразу после «Остановить»**. В частичном архиве имя файла получает пометку `остановлено`, `chapters.txt`/`ComicInfo.xml` содержат `Неполных глав: N`, а неполная текущая глава получает папку с суффиксом `неполная`, помечается `НЕПОЛНАЯ` и её страницы переиндексируются без дыр.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `downloads` | сохранение CBZ и картинок в папку загрузок |
| `tabs`, `activeTab` | определить URL активной вкладки MangaLib / SlashLib / HentaiLib |
| `scripting` | чтение `data-id` и запасные запросы из контекста сайта при WAF/CORS |
| `declarativeNetRequestWithHostAccess` | установить `Referer` для API/CDN |
| `storage` | запомнить формат, скорость и папку в загрузках между запусками |
| `host_permissions` | три сайта, их зеркала, API и известные домены картинок (`cdnlibs.org`, `hentaicdn.org`, `imglib.info`, `hentailib.me`, `hentailib.org`) |
| optional `https://*/*` | только на случай нового CDN; запрашивается отдельно кнопкой/при старте скачивания и не активно по умолчанию |

## Ограничения

- Скачиваются только главы, которые публичный API отдаёт без обхода. Платные главы, ранний доступ, DRM, капча и обход авторизации **не поддерживаются**. Тайтлы 18+ могут быть доступны, если пользователь уже вошёл на сайт и сам подтвердил возраст; расширение лишь передаёт его токен, но не обходит возрастную проверку. Закрытые ветки помечены в списке и отключены.
- У лицензированных тайтлов API может возвращать пустой список глав — это нормально, расширение покажет предупреждение.
- Сайт ограничивает частоту запросов; при `429` расширение ждёт и повторяет запрос. Для больших тайтлов лучше качать порциями и использовать режим «Бережно».
- Режимы «Один …» держат все страницы выбранных глав в оперативной памяти до сборки архива. Архив собирается без лишней полной копии (Blob из частей), но сами страницы всё равно живут в памяти: для очень больших выборок используйте режим «CBZ — архив на главу» или качайте частями.
- Формат — ZIP32 (метод `STORED`), поэтому один архив ограничен **4 ГиБ и 65 535 файлами**. При выходе за лимит расширение не сделает битый файл, а выдаст ошибку с предложением качать частями.
- Папка в загрузках запоминается, только если вы её меняли вручную: по умолчанию подставляется `MangaLib` / `SlashLib` / `HentaiLib` по сайту.
- API неофициальный и может измениться. Если адреса или CDN поменяются, обновите `SITE_PROFILES` в `core.js`, домены в `background.js` и `host_permissions` в `manifest.json`.
- Используйте для личного офлайн-чтения и соблюдайте правила сайта и права правообладателей.

## Диагностика

- **403 / «API недоступен»**: откройте страницу тайтла на нужном сайте, нажмите **Обновить доступ**, перезагрузите расширение на `chrome://extensions`. Кнопка теперь ещё и пишет в журнал, каких именно хостов не хватает.
- **404**: проверьте сайт в выпадающем списке, `Site-Id` в левой колонке и то, что ссылка ведёт именно на MangaLib / SlashLib / HentaiLib. Для SlashLib сейчас актуален домен `v2.shlib.life`, для HentaiLib — `hentailib.me`. Если тайтл помечен 18+, войдите на сайт, подтвердите возраст, не закрывайте вкладку и нажмите **Загрузить список** ещё раз: расширение подхватит Bearer-токен из `localStorage`. Ниже появятся похожие тайтлы, если точный всё равно недоступен.
- **Файл не появляется сразу**: в режимах «Один …» это нормально — дождитесь статуса `Готово. Отдан 1 архив`. При остановке появится статус `Остановлено. Отдан 1 архив…` и частичный файл с пометкой `остановлено`. Не закрывайте вкладку загрузчика, пока не увидите статус.
- **Глав нет**: тайтл может быть лицензирован, удалён или требовать недоступный раздел.
- **Картинки не скачиваются**: в DevTools на странице чтения найдите фактический хост изображений и добавьте его в `fallbackServers` профиля в `core.js` и в `host_permissions`. Если хост новый, после `/constants` расширение напишет в журнал, что доступа к нему нет — нажмите **Обновить доступ**.
- **Ошибки в консоли**: откройте DevTools (F12) на вкладке расширения и/или `chrome://extensions` → «Проверить представления: service worker».

## Оформление

Интерфейс собран как **библиотечный формуляр**: один холодный бумажный лист, petrol ink, один кобальтовый акцент и каталожные строки глав. Это замена старого тёмно-фиолетового дашборда, а не его «полировка».

Использованные подходы:

- [Impeccable](https://github.com/pbakaus/impeccable) — `new-work`, `craft-floor`, `distill`, `clarify`, `audit`, `polish`; режим `Operate`, отказ от карточек-в-карточках, gradient text, glassmorphism, side-stripe borders и шаблонных kicker-подписей.
- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) — явный отказ от перечисленных там AI-default миров: warm cream + serif + terracotta, near-black + acid accent, broadsheet, SaaS-card kit.
- Локальные `PRODUCT.md`, `DESIGN.md` и `SURFACE-BRIEF.md` фиксируют product truth, палитру, типографику и brief поверхности.

Шрифты **Unbounded**, **IBM Plex Sans** и **IBM Plex Mono** лежат в `fonts/` вместе с OFL-лицензиями и подключаются через локальный `fonts/fonts.css`. Сеть не используется: CSP разрешает только `script-src`, `style-src` и `font-src` с `'self'`. Из 38 подмножеств оставлены только нужные (кириллица, латиница, latin-ext, греческий) — 24 `@font-face`, без вьетнамского и cyrillic-ext.

Проверки, которые действительно можно повторить:

```bash
node --test tests/design.test.mjs
```

Тест запрещает градиенты, glassmorphism, uppercase-лейблы, border-left-полосы, старую фиолетовую палитру, шаблонные точки/стрелки, inline-стили и внешние шрифты, а также проверяет контраст закрытых глав, тач-таргеты 40 px и мобильные grid-области строки главы.

## Структура

```text
LibDownloader/           # корень репозитория = корень расширения
  manifest.json          # Manifest V3, permissions, host permissions, CSP
  background.js          # модульный service worker: импортирует core.js и ставит DNR-правило Referer
  app.html               # интерфейс-формуляр
  app.css                # дизайн-система без внешних ресурсов
  fonts/                 # self-hosted OFL-шрифты и fonts.css
  core.js                # профили сайтов, заголовки, парсинг, ZIP/CRC32, наборы файлов архивов
  app.js                 # API, загрузка страниц, выбор глав, downloads
  icons/                 # PNG 16/32/48/128
  PRODUCT.md             # product truth
  DESIGN.md              # палитра, типографика, layout, anti-slop правила
  SURFACE-BRIEF.md       # brief конкретной поверхности
  REVIEW.md              # аудит кода и дизайна с разбором найденных дефектов
  tests/                 # тесты без npm-зависимостей
```

## Тесты

Нужен только Node.js 18+:

```bash
node --test tests/*.test.mjs
```

Покрыты:

- парсинг URL/slug всех трёх сайтов (включая отказ от `javascript:`/`ftp:`), профили `Site-Id`, origin, домены DNR;
- заголовки API: `Site-Id`, `Accept` и правило, по которому Bearer-токен уходит только на `authHosts` профиля;
- переводы и закрытые главы, диапазоны, метки глав без тома, XML-экранирование, CRC32;
- ZIP: части, лимиты ZIP32 (65 535 записей), уникальные имена, вложенный CBZ внутри общего ZIP;
- сборка архивов вынесена из `app.js` в `core.js` и проверяется целиком: папки по главам, плоский CBZ, вложенные CBZ, частичная глава после «Остановить», `chapters.txt` и `ComicInfo.xml`; каждый архив дополнительно распаковывается настоящим `zipfile` из Python, если он есть в системе;
- manifest, CSP, host permissions всех трёх сайтов, локальные шрифты и их подмножества, anti-slop правила CSS/разметки.

Логика, которая требует Chrome API (сеть, `chrome.downloads`, `scripting`), тестами не покрыта и проверяется вручную по разделу «Диагностика».
