# Surface brief — `app.html`

- **Scope**: the extension's single options/loader page; replacement visual world, not a new product.
- **Visitor mode**: Operate. The visitor completes a task, not decides whether to buy something.
- **Audience**: a Chrome user already on MangaLib/SlashLib who wants chapters in one archive.
- **Job**: paste/detect a title, select chapters and translations, start, stop if needed, receive one archive.
- **Proof/content**: real chapter rows, counts, Site-Id/API, status, progress and log. No invented marketing content.
- **Chosen direction**: circulation slip / library register; see `DESIGN.md`.
- **Memorable moment**: the single sheet reveal plus the spine-like chapter numbering, not a hero graphic.
- **Constraints**: MV3 CSP, no network fonts/scripts, all existing IDs and behaviour preserved, Russian copy, offline preview.
- **Unresolved**: none; user delegated the direction choice.
