    Как это работает и ограничения
    • Используется только публичный JSON API сети lib.social: список глав, страницы главы и список серверов изображений. Для MangaLib передаётся Site-Id: 1, для SlashLib Site-Id: 2, для HentaiLib Site-Id: 4.
    • Общий CBZ по умолчанию содержит папку на каждую главу, внутри страницы и ComicInfo.xml главы; в корне лежат общие chapters.txt и ComicInfo.xml.
    • Расширение не обходит вход в аккаунт, платный доступ, DRM, капчу или возрастные ограничения. Для части 18+ тайтлов SlashLib и HentaiLib оно использует уже имеющийся токен авторизации сайта и отправляет его только на API-хосты профиля; если API всё равно вернул 404, появятся похожие тайтлы из каталога.
    • Не закрывайте вкладку загрузчика до окончания. При первой пакетной загрузке Chrome может попросить разрешение на несколько файлов.
    • Если сайт изменит адрес API или CDN, проверьте запрос .../chapter?number=…&volume=… на вкладке Network в DevTools и обновите константы в app.js.
